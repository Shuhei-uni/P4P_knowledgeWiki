# CFD evidence lookup

Perform a quick CFD paper-lookup scan before deciding evidence or prior research for work involving CFD model choices, solver setup, boundary conditions, mesh or numerics, validation or uncertainty, geothermal separator design, steam-water separation, carryover, steam purity, entrainment or deposition, annular flow, geofluid properties, downstream ORC implications, or multi-step project decisions that prior papers might change.

1. Read `CFD_wiki/paper_lookup/index.md`.
2. Open only relevant chunk files under `CFD_wiki/paper_lookup/`.
3. Identify applicable source, setup, synthesis, or raw-paper sections.
4. Carry applicable evidence into the answer or wiki update with citations and uncertainty labels.
5. If none applies, state that the lookup was checked and yielded no relevant prior-paper guidance.

This is a targeted evidence scan, not a full ingest. Do not read every lookup chunk unless the task genuinely requires it.
