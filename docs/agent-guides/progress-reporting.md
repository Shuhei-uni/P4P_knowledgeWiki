# Progress reporting

Whenever a user asks for “progress” (including “show progress”, “update progress”, or “what's the progress”), append a dated entry to `ResearchProject_wiki/wiki/log.md` using the `progress-update` operation tag. Include what changed since the previous update, current status, blockers if any, and the next action.

Also synchronize `ResearchProject_wiki/wiki/progress/current-status.md` when it exists. This applies even when the underlying technical work occurred in `CFD_wiki/`.
