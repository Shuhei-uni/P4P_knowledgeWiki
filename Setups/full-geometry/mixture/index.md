# Full Geometry — Mixture Setup Campaigns

This area retains **setup definitions and plans** for continuous-phase Mixture-model campaigns on the full geometry. New selected experiments belong under `Project/experiments/`.

Numerical reports are kept separately under [Setups/reports/full-geometry/mixture](../../reports/full-geometry/mixture/index.md).

- [Transient liquid-outlet characterization](transient-liquid-outlet/index.md) — retained major campaign; its setup and execution records remain available as provenance for the Project experiment route.

## Retained rule

Existing Mixture setup records remain inside descriptive campaign folders. Preserve old setup numbers as historical aliases where useful; do not create new selected experiments or continue the global `02f`, `02g`, ... sequence here.

Every retained campaign should link to its mirrored report folder even when that report folder contains only an index and no results yet.
