# Full Geometry — Mixture Setup Campaigns

This area owns **setup definitions and plans** for continuous-phase Mixture-model campaigns on the current full geometry.

Numerical reports are kept separately under [Setups/reports/full-geometry/mixture](../../reports/full-geometry/mixture/index.md).

## Campaigns

- [Steady liquid-outlet characterization](steady-liquid-outlet/index.md) — existing `02c`/`02e` setup lineage reorganized semantically.
- [Transient liquid-outlet characterization](transient-liquid-outlet/index.md) — current major campaign; qualifies startup and transient numerics before applying the aggressive retention screen.

## Rule

New Mixture setup work lives inside a descriptive campaign folder. Preserve old setup numbers as historical aliases where useful, but do not continue the global `02f`, `02g`, ... sequence just to name new full-geometry experiments.

Every campaign should link to its mirrored report folder even when that report folder currently contains only an index and no results yet.
