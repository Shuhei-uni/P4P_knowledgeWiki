## Classification rule

Do not classify geometry from the setup number alone. Some historical notes use terms such as “full geometry” to mean a complete vessel/domain while still using the older `purnanto` geometry label. Treat a legacy record as current full-geometry only when explicit mesh/case provenance proves it belongs to `Full-geomV2` or a verified descendant.

## New-work rule

Do not extend this programme simply because a new number is available. New `Full-geomV2` campaigns belong under [`Setups/full-geometry/`](../full-geometry/index.md).
