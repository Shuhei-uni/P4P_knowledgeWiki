# Poster section drafts

Open `index.html`, then select a section. Each section HTML can be edited independently. `sections.css` provides the shared visual style; `sections.js` controls source-note visibility and reports failed image loads.

Existing images remain in their original locations. Keep these drafts inside the repository so relative links work. The figure register lists existing assets and explicit requests for missing figures. Source and checklist notes sit outside each proposed poster section and can be hidden with the page button. Printing hides those review notes, but retains missing-figure placeholders.

These are working sections for an A1 poster. Their final physical sizes, arrangement and print legibility are not established yet. No separator design result is included. The findings plan in the parent folder owns the communication argument; experiment records own the science.
