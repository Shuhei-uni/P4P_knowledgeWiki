# Phase 4 — EWF wall-film mechanisms

## Scientific purpose

Investigate wall-film deposition, drainage, splash, edge separation, particle
stripping, and global EWF/DPM coupling on the executed carrier branches.

## Retained experiments

- [purnanto-010V2-clean-ewf-deposition](purnanto-010V2-clean-ewf-deposition/results.md) — executed diagnostic; not an accepted clean control.
- [purnanto-010V2a-ewf-splash](purnanto-010V2a-ewf-splash/results.md) — executed splash diagnostic.
- [purnanto-010V2b-ewf-edge-separation](purnanto-010V2b-ewf-edge-separation/results.md) — executed partial and later quantitative diagnostic.
- [purnanto-010V2c-ewf-particle-stripping](purnanto-010V2c-ewf-particle-stripping/results.md) — executed diagnostic; stripping effect unresolved.
- [purnanto-010V2d-ewf-combined-mechanisms](purnanto-010V2d-ewf-combined-mechanisms/results.md) — executed continuation diagnostic; later endpoint degraded.
- [purnanto-010V2d-2-ewf-global-dpm](purnanto-010V2d-2-ewf-global-dpm/results.md) — executed global-DPM/EWF continuation diagnostic.
- [purnanto-10a-splash-ewf-preliminary](purnanto-10a-splash-ewf-preliminary/results.md) — executed splash-enabled preliminary diagnostic.

## Phase outcome

The executed records provide evidence of finite films and mechanism-related
event signals, but none establishes a converged, mass-closed EWF or separator
performance result. The combined continuation also records film-CFL growth
and degraded numerical state, so longer endpoint-only snapshots are not a
sufficient qualification path.

## Remaining uncertainty

Interval EWF histories, generated-particle ledgers, complete carrier balance,
and matched mechanism controls remain unavailable. The preliminary `10a`
record is explicitly splash-enabled and must not be used as a clean control.
