# R0 control-window plots

All plots for the R0 smooth-control record are consolidated here.

- `control-*` — the terminal 1000-iteration comparison control window from
  `run4`.
- `warmup-*` — the preceding 1000-iteration continuation retained for
  provenance only; it is not pooled into control-window statistics.

The control window uses the second continuation, expected native coordinates
4580–5580 with restarted transcript rows 4586–5586. Report cadence was every
native iteration; solver calls were made in batches of 100.
