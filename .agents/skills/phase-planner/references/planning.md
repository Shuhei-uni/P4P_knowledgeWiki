# Planning reference

Use this only when the phase direction is genuinely unsettled.

## Catch up

Reconstruct the frontier from current Project evidence and Git history. Bring in
`CFD_wiki` or external literature only for facts that could change the
decision. Use live Fluent inspection only when capability constrains the science.

## Shape candidates

Turn the uncertainty into a small number of contrasting mechanisms or experiment
families. Compare them on:

- what uncertainty they reduce;
- what evidence would distinguish them;
- cost and implementation risk;
- whether they stay inside the intended model/scope.

Do not multiply candidates for completeness.

## Human decision boundary

Ask the human to choose or modify the **direction/envelope**, not implementation
steps. Once the envelope is clear, record it and let `phase-loop` work inside
it.

If a speculative idea needs research, research it now and report whether it is
plausible and testable; research does not need a separate approval skill.
