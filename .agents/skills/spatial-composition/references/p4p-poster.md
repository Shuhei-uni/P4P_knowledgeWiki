# P4P poster adapter

Use this only for the separator poster or related P4P visual communication.
It adapts the general workflow; it does not own current science, selected figures,
poster dimensions or the approved palette.

## Locate the current owners

Start with the user-selected artifact and inspect the relevant files under
`Project/meetings/Poster/`. Existing entry points include:

- [Poster design definition](../../../../Project/meetings/Poster/P4P_POSTER_DESIGN.md): visual decisions and earlier constraints.
- [Poster findings plan](../../../../Project/meetings/Poster/P4P_POSTER_FINDINGS_PLAN.md): content framing; consult only when it affects placement or required content.
- [Existing HTML draft](../../../../Project/meetings/Poster/P4P_POSTER_DRAFT.html) and [section drafts](../../../../Project/meetings/Poster/poster-sections/README.md): current construction and asset routes.

Read the latest explicit brief before applying an old design rule. The earlier
design definition describes a flat, quiet treatment. The later visual-redesign
request explores a colourful enlarged flow-field background and a prominent
separator. Treat that as a change to the relevant visual direction, not permission
to change scientific results or discard every other requirement. Check current
format decisions rather than scaling an old poster specification by assumption.

## Translate this direction into roles

The following is a candidate relationship model, not a locked layout:

| Element | Job | Relationship to test |
|---|---|---|
| Enlarged colourful bulk-flow image | Attract interest and establish the flow environment. | Behind the composition; preserve energy outside protected text and silhouette regions. |
| Accurate separator illustration | Give the viewer a recognisable subject. | In front of the field; test crossing a supporting boundary without hiding evidence. |
| Supporting scientific figures | Explain the work. | Crisp, readable groups with captions and restrained containers. |
| Title and optional framing line | Identify and orient. | Protected text region connected visually to the subject; no invented claim. |
| Fine labels and callouts | Support close inspection. | Above their targets but quieter in global attention. |

Show each candidate's layers and relationships, not just where Methods and Results
go. The main visual may be central or offset. Keep variants comparable using the
same content, assets, format and protected requirements.

## Preserve the engineering meaning

Use supplied geometry and verified case references for the separator. Distinguish
the simplified computational domain from the complete physical separator; do not
invent a lower cone, move an inlet, change the outlet, or alter the retained liquid
region to improve the silhouette. Treat conceptual flow arrows as schematic,
not extracted trajectories, unless they actually come from the solution.

For field images and plots, follow the evidence/atmosphere distinction in
[editable construction](editable-construction.md). Leave raw results unchanged.
An attractive contour does not establish convergence, validation, or optimisation.
Use [CFD figure guidance](../../cfd-numerical-analysis/references/figures.md) when a
new evidence figure is genuinely required; this skill does not start Fluent runs.

Keep the current asset locations and reproducible figure-generation paths when
possible. Prefer improving the editable draft over flattening it into one image.
A request to create or improve this skill alone does not authorise poster edits.
