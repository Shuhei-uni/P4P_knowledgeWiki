# Methods and reproducibility

## Explain how each answer was obtained

Connect each method to the question or result it supports. Describe what was actually done. Give enough detail for an informed reader to assess and reproduce the work, and explain choices that materially affect interpretation. Use existing project records before asking for missing information.

Describe standard methods briefly, cite an appropriate original source, and identify the actual implementation and modifications. Explain the choices made in this study; avoid reproducing textbook material or software instructions that do not help the reader evaluate the result.

## Check the evidence needed for the study type

Use the applicable parts of this list:

- Experimental work: specimens or participants, instruments, calibration, conditions, controls, repetitions, exclusions, and analysis.
- Computational work: inputs, geometry or datasets, assumptions, model versions, boundary and initial conditions, numerical settings, stopping criteria, and extraction of reported quantities.
- Theoretical work: definitions, domains, assumptions, derivation or proof, approximation steps, and conditions of validity.
- Design evaluation: requirements, alternatives, constraints, evaluation criteria, and the basis for the selected option.

State units and operational definitions for quantities used later. Explain how averages, error measures, efficiencies, and comparison baselines were calculated. Separate a declared method from later deviations or exploratory changes.

## Keep detail useful and traceable

Group methods so readers can locate the procedure behind each result. Put details needed to judge a central claim in the main account. Use appendices or linked materials for lengthy settings, derivations, or repeated procedures, with precise cross-references.

If a parameter or version is absent from the record, mark the specific gap. Do not infer that a software default was used. Never add an experiment, calibration, repeat, or verification step because the report would be stronger with it.

Illustrative distinction: "Three time-step sizes were compared" describes completed work only if that comparison exists. "A time-step study is needed" describes an outstanding check.

Basis: [MIT EECS Communication Lab, Methods](https://mitcommlab.mit.edu/eecs/commkit/journal-article-methods-ee/). The study-type inventory is an original application.
