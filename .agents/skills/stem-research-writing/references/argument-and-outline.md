# Argument and report outline

## Build the argument from the available work

Write a provisional answer to the research question in ordinary language. Treat it as a statement to check against the evidence. If the main contribution or intended emphasis remains open, show a recommended framing with its reason and ask which direction the user wants. For incomplete work, identify the question answered so far and the question still open.

For a substantial draft, sketch a compact map:

| Question | Evidence available | Defensible answer | Limit | Destination |
| --- | --- | --- | --- | --- |
| What was the study trying to establish? | Figure, table, calculation, observation, or source | What that evidence supports | What remains uncertain | Section or subsection |

Keep the map lightweight. Reuse existing notes; do not create a separate project-management system. Show it when the user asks for a flow or when it helps explain a structural change.

## Choose an order the reader can follow

Use the supplied brief and report structure. Within that structure, arrange material so readers understand a question before encountering the evidence that answers it. Group comparisons that answer the same question. Identify necessary dependencies, such as a baseline that must be understood before a modification can be assessed.

Use chronological order when the sequence itself explains a decision, a causal process, or a staged investigation. Otherwise, organise by questions and findings. Preserve the distinction between planned tests and later exploratory work even when reorganising the narrative.

Adapt the structure to the kind of work:

| Work | Useful organising unit |
| --- | --- |
| Experimental study | Question, comparison, observation, interpretation |
| Computational study | Model assumptions, numerical credibility, predictions, limits |
| Theoretical study | Definitions, assumptions, propositions, derivation, consequences |
| Engineering design study | Requirements, alternatives, evaluation, justified choice |
| Literature-based study | Themes, agreements, disagreements, gaps, synthesis |

Use introduction, methods, results, and discussion where they fit. Allow combined sections and several connected research questions. A failed hypothesis or a bounded methodological contribution can still provide a coherent report.

## Check the connections

Read the objective, proposed subsection headings, and conclusion together. Check that each promised objective has an answer, a partial answer, or an explicit unresolved status. Remove conclusions that lack a route back to evidence. Name headings by the question or finding where permitted; keep required headings intact.

Basis: [Mensh and Kording, Ten simple rules for structuring papers](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005619). The mapping procedure and study-type adaptations are original operational guidance.
