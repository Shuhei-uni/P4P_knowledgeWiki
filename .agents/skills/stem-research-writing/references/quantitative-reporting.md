# Numbers, comparisons, and statistical language

## Make each number interpretable

Identify the quantity, units, reference condition, aggregation, and interval. Define an error or efficiency measure before interpreting it. State what a denominator includes. Preserve signs, normalisation, precision, and uncertainty when editing.

Distinguish instantaneous values, averages, maxima, totals, and time-integrated quantities. A mean of ratios need not equal a ratio of means. Check that the calculation described in the prose is the one actually performed.

## Check comparisons

Use matched conditions or state their differences. Name the baseline for a relative change. For a positive non-zero baseline b and new value a, the relative change is (a - b) / b; multiply by 100 to express it as a percentage. Prefer an absolute comparison when a near-zero or negative baseline makes the percentage misleading.

Illustrative only: an efficiency increase from 80% to 88% is 8 percentage points, or a 10% relative increase from the 80% baseline. The two descriptions are not interchangeable.

Check arithmetic with a calculator or code when needed. Do not infer missing precision or read an exact value from a low-resolution plot. Make rounding consistent with the uncertainty and the report's conventions.

## Use statistical claims only when warranted

When statistical analysis is present, distinguish effect size, uncertainty, and the result of a specified test. A p-value does not measure effect size, practical importance, or the probability that a hypothesis is true. A threshold crossing alone is not a sufficient scientific conclusion.

Identify what error bars represent and the independent unit of analysis. Do not automatically treat successive time samples, mesh cells, or solver iterations as independent experimental replicates. Do not invent statistical tests for a deterministic comparison.

Avoid converting a non-significant difference into proof of equality. State the estimate and available uncertainty, and distinguish insufficient evidence from evidence supporting a defined equivalence claim. When uncertainty was not assessed, say so if it affects the conclusion; do not manufacture intervals.

Basis for statistical cautions: [American Statistical Association, Statement release on p-values](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf). The numerical checks and examples are original operational guidance.
