# STEM Research Writing

Help the reader understand the question, the evidence, the answer, and its limits. Write clear scientific English that the author can recognise as their own.

## Repository use

Use this workflow for requests centred on academic argument, findings to emphasise, report flow, or language. [Report Writing](../report-writing/SKILL.md) owns assembly of `Project/` records and figures into a project technical report. Choose one owning workflow and consult only the references needed from the other.

When project evidence is needed, start at [Project/index.md](../../../Project/index.md) and read the selected records. Cite external sources for scientific background. For Markdown under `Project/experiments/`, follow the [experiment presentation contract](../../../Project/experiments/README.md#presentation). Use document-relative links and images in repository documents.

## Work within the request

Identify the requested operation, report section, audience, brief or rubric, length, language convention, and available evidence from the conversation and supplied files. Respect explicit instructions and the existing report's requirements. Preserve technical facts; flag contradictions rather than smoothing them away.

For a grammar-only edit, keep the argument and structure intact. For drafting, critique, or substantive revision, work from evidence and report logic toward paragraphs, sentences, and words. Use precise specialist terms with plain surrounding language. Preserve the author's voice; use New Zealand English for a new report if no other convention is supplied.

Read only the references needed for the task. Start with one to three and load further files when a concrete issue requires them. For a long report, work section by section. Do not load the entire folder automatically.

## Ask questions and offer a direction

Before settling the direction of substantial drafting or revision, check for unresolved choices about the objective, main contribution, findings to emphasise, report flow, audience, scope, or depth of editing. Ask one to three focused questions early when such choices remain. When several defensible framings exist, ask the user's preference even if one seems likely; do not treat your inference as an agreed decision.

Pair each question with a concrete suggestion and a brief reason. Offer two or three meaningful options when useful, identifying the recommended option and its trade-off. For missing research facts, ask what evidence exists and recommend how to handle the gap; never suggest an invented fact as an answer. Read [Questions and suggestions](references/questions-and-suggestions.md) for patterns.

Use answers already supplied and carry new answers through the task. Keep routine edits moving. While a question is open, complete independent work and label any proposed direction as provisional. If an optional preference question receives no answer, continue with an explicitly stated recommendation; keep unsupported factual claims unresolved.

## Draft and revise

1. Establish what the supplied evidence can support and ask about consequential unresolved choices. For substantive work, connect each main finding to a question, evidence, comparison, and material limit. Keep working notes small; show an outline or evidence table when useful or requested.
2. Use the user's answers to choose the findings and order that answer the research question. Keep unanswered editorial choices visibly provisional. Include material failures, contradictions, and uncertainty. Follow the required structure; adapt journal conventions to the report rather than forcing a template.
3. Produce the requested text. Develop each paragraph around a clear job. Separate observations, model predictions, interpretations, assumptions, and proposals through accurate wording.
4. Improve grammar, word choice, and sentence connections without changing the science. Do not strengthen a claim during a language-only edit. Preserve useful existing prose and defined terminology.
5. Check the result at the requested scale: objectives answered; claims supported; material qualifications retained; numbers and comparisons consistent; citations and cross-references correct; paragraphs connected.

Never invent results, methods, sources, quotations, identifiers, or completed analyses. If evidence is missing, ask the relevant factual question and narrow the text or mark the specific gap. Complete supported work while keeping the dependent claim open; do not turn collaborative questions into routine approval pauses.

Return the requested outline, prose, revision, or critique in the requested format. Add concise notes on substantive changes and unresolved evidence when useful. Use bullets for plans and parallel material, and connected prose for narrative sections. Use document tools separately when file editing or rendering is requested; do not introduce layout work or compulsory figures into a writing task.
