# Figures

Every core figure must answer one scientific question.

Prefer native Fluent post-processing for spatial CFD evidence. Preserve source
case/data identity and do not alter the scientific pixels after export.

For each figure define:

- message/question;
- exact source run/artifact;
- field/surface/time-window;
- comparison range/normalisation;
- caption-level observation.

Keep comparable cases visually comparable: same units, scalar limits, view, and
surface definition when those choices carry meaning.

Use roughly 1–3 core figures for discovery and 2–5 for deeper qualification.
Additional debug figures stay supporting evidence.

A missing figure that is required for the planned judgement triggers
reconstruction/rerun recovery; it is not replaced by a broad prose claim.
