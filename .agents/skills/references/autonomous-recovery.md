# Autonomous recovery

A `BLOCK` in an active Phase Loop or Auto Loop starts diagnosis, not permission
to waive a gate. Recover within the recorded phase envelope or continue an
independent valid lane. Use the shared
[MCP integration](../fluent-live-inspection/mcp-integration.md) contract for
all live Fluent work and any retained-worker exception.

## Recover in this order

1. **Reconcile** the exact setup, `CONTEXT.md`, `phase-state.yaml`, run manifest,
   canonical paths and closest verified pair. After a lost response or execution
   error, establish whether the old operation is still running or partly applied.
   A timeout, filename or new client does not settle that question. Preserve the
   block and inspect recorded progress/live state when safely available before
   replaying anything; never add a competing writer.
2. **Inspect and research** with MCP-backed `fluent-live-inspection`, `cfd-wiki`
   for reusable evidence, and `fluent-manual-researcher` for version-matched
   semantics. Use focused official/external research when coverage is missing.
   MCP failure does not authorize a crawler, raw PyFluent/TUI workaround or
   disabled sandbox checks. A named existing worker may supply a demonstrated
   missing capability only under the shared exception contract.
3. **Choose the leanest authorized repair**: path/instrumentation correction;
   verified equivalent implementation or parent recovery; a small diagnostic
   family preserving the question; or an explicitly labelled, researched
   `Assumed` surrogate bracketed by sensitivity when an external fact is missing.
   Never fabricate plant facts or scientific permission.
4. **Prove and record** rationale, evidence, controlled delta, assumptions and
   recovery gate in the existing context/setup/run/results records as applicable.
   Validate/run permitted mutations through MCP, read back, save/reopen and smoke
   test required streams before compute. Preserve exact parents and claim limits.

## Continue within authority

Ordinary blockers need not pause the whole loop for a human reply. If available
recovery is exhausted, persist `BLOCKED_AUTONOMOUS`, failed evidence, retained
artifacts and the next permissible recovery, then continue useful authorized work
until the stop time. Do not silently replace the phase question or mark an
attempt/partial result `PASS`.

Autonomy does not create missing permission: human-only patching or explicitly
approved TUI/journal exceptions remain restricted. Record/defer that lane when
approval is absent rather than infer it or stop every independent lane. Preserve
Fluent processes and valuable paired state; restarting Fluent is not recovery.
